# NODEJS MASTER AUTH

A comprehensive authentication system built with Node.js and TypeScript. This project provides a robust and secure authentication API with features including user registration, login, logout, token refresh, and role-based authorization. Built with MySQL database integration and following best practices for error handling and validation.

## Features

- User registration and login
- JWT-based authentication with access and refresh tokens
- Token refresh mechanism
- Secure logout functionality
- Role-based authorization
- MySQL database integration
- Input validation with schemas
- Centralized error handling
- Health check endpoint
